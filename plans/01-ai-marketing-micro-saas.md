# AI 마케팅 콘텐츠 자동화 스튜디오

> 유튜브 URL이나 상품 설명을 입력하면 브랜드 톤에 맞춰 뉴스레터·스레드·카드뉴스 문구를 생성하고 노션으로 내보내는 Micro-SaaS

## 기본 정보
- **SaaS 유형**: Micro-SaaS, Prosumer, AI-native
- **진행 상태**: 기획중
- **핵심 타깃 고객**: 1인 마케터, 소규모 브랜드 운영자, AI 콘텐츠 크리에이터
- **수익 모델**: Freemium (월 10 크레딧) + Pro 월 구독 (크레딧 기반 과금)
- **기술 스택**: Next.js, TypeScript, Supabase, OpenAI API, SSE, Tailwind CSS
- **라이브 데모**: (예정)
- **GitHub**: (예정)

## 1. 문제 정의 & 타깃 고객 (Why)
- 마케터가 하나의 콘텐츠(영상/블로그)를 채널별(뉴스레터, 인스타, 스레드)로 재가공하는 데 매번 2~3시간을 소모함.
- 범용 챗봇에 매번 브랜드 톤과 포맷을 복붙해 지시하는 과정이 반복적이고 결과 품질이 일정하지 않음.

## 2. 핵심 기능 & 사용자 흐름 (What / MVP Scope)
- **핵심 기능 1**: 브랜드 보이스(톤앤매너, 금지어, 타깃 독자) 프로필 저장
- **핵심 기능 2**: 원문/링크 입력 시 3개 채널용 콘텐츠를 SSE 스트리밍으로 동시 생성
- **핵심 기능 3**: 생성 히스토리 저장, 원클릭 복사 및 노션/Webhook 내보내기
- **사용자 흐름**: 로그인 → 브랜드 프로필 선택 → 원문 입력 → 생성(크레딧 차감) → 편집 및 내보내기

## 3. SaaS 비즈니스 구조 (과금 · 권한 · 멀티테넌시)
- 무료 플랜: 월 10 크레딧, 브랜드 프로필 1개
- 유료 플랜(Pro): 월 300 크레딧, 무제한 프로필, 노션 자동 내보내기
- 사용량 측정(Metering): 생성 API 호출 전 트랜잭션으로 잔여 크레딧 검증 및 차감, 실패 시 자동 환불

## 4. 시스템 아키텍처 & DB / API 설계
- 프론트/백엔드: Next.js App Router + Route Handlers
- DB/인증: Supabase (PostgreSQL + Auth + RLS)
- 주요 테이블: `users`, `brand_profiles`, `generations`, `credit_ledger`
- AI 파이프라인: 원문 요약 → 채널별 구조화 프롬프트 실행 → SSE 스트리밍 전송

## 5. 기술적 의사결정 & 트레이드오프 (ADR)
- **[선택 1]** 일반 JSON 응답 대신 SSE 스트리밍 적용
  - 이유: LLM 생성에 6~12초가 소요되어 빈 로딩 화면 대신 첫 토큰을 1초 내에 보여줘 체감 속도를 높이기 위해.
- **[선택 2]** 크레딧을 단순 숫자 덮어쓰기가 아닌 `credit_ledger` 원장 테이블로 기록
  - 이유: 결제·차감·환불 이력을 감사(Audit)하고 동시 요청 시 정합성을 지키기 위해.

## 7. 3분 발표 대본 & 예상 꼬리질문 Q&A
- **3분 요약**: 마케터의 반복 콘텐츠 재가공 문제를 해결하는 AI-native Micro-SaaS입니다. 단순 AI 래퍼를 넘어 브랜드 컨텍스트 관리, SSE 스트리밍 UX, 원장 기반 크레딧 과금 구조까지 풀스택으로 설계했습니다.
- **예상 질문 Q1**: 동시에 생성 버튼을 두 번 누르면 크레딧이 중복 차감되지 않나요?
  - **A1**: Idempotency Key와 DB 트랜잭션(조건부 업데이트)으로 중복 요청을 차단했습니다.
