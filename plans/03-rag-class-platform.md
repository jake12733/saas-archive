# RAG AI 튜터 미니 구독형 클래스 플랫폼

> 강사가 강의 자료를 업로드하면 수강생이 구독 후 학습하고, 강의 자료 근거 기반 AI 튜터에게 24시간 질문하는 B2B2C 교육 SaaS

## 기본 정보
- **SaaS 유형**: B2B2C, Vertical, AI-native
- **진행 상태**: 기획중
- **핵심 타깃 고객**: 지식 크리에이터, 온라인 강사, AI 교육 수강생
- **수익 모델**: 수강생 월 정기 구독 + 강사 수수료 모델
- **기술 스택**: Next.js, TypeScript, Supabase pgvector, RAG, Stripe/Toss Test
- **라이브 데모**: (예정)
- **GitHub**: (예정)

## 1. 문제 정의 & 타깃 고객 (Why)
- 온라인 강의 수강생이 실습 중 막혀도 강사 답변을 기다리다 학습을 포기함.
- 일반 AI에게 물어보면 강의 커리큘럼과 다른 엉뚱한 답(할루시네이션)을 줄 때가 많음.

## 2. 핵심 기능 & 사용자 흐름 (What / MVP Scope)
- **핵심 기능 1**: 강사 대시보드에서 강의 노트/PDF 업로드 시 자동 청킹 및 벡터 임베딩
- **핵심 기능 2**: 수강생 전용 학습 뷰 + 강의 자료 출처(섹션)를 함께 표시하는 RAG 챗봇
- **핵심 기능 3**: 구독 결제(테스트 모드) 및 웹훅 기반 수강 권한 자동 부여/회수

## 3. SaaS 비즈니스 구조 (과금 · 권한 · 멀티테넌시)
- 무료 체험: 1강 미리보기 + AI 튜터 질문 5회
- 구독 회원: 전체 강의 열람 + AI 튜터 무제한(Fair-use Rate Limit 적용)

## 4. 시스템 아키텍처 & DB / API 설계
- 주요 테이블: `courses`, `lessons`, `document_chunks(vector)`, `subscriptions`, `chat_messages`
- RAG 파이프라인: 텍스트 추출 → 500토큰 청킹(오버랩 100) → 임베딩 저장 → 유사도 검색 Top-K → 출처 포함 답변 생성

## 5. 기술적 의사결정 & 트레이드오프 (ADR)
- **[선택 1]** 별도 벡터 DB 대신 PostgreSQL + `pgvector` 사용
  - 이유: 수강 권한(`subscriptions`)과 벡터 검색을 같은 DB 쿼리 조건으로 묶어 권한 없는 강의 문서가 검색되는 문제를 원천 차단하기 위해.
